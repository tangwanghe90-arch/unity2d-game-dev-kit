# Unity 2D Game Dev Kit

一套自包含的 Unity 2D 小游戏开发模板与教程，包含通用组件、演示场景、接入指南和完整工程。

## 下载

下载仓库根目录的 `Unity2D_Game_Dev_Kit.zip`，解压后先看里面的 `README.txt`。

## 内容

- 18 个通用组件脚本，两套可玩演示场景
- 已有工程接入指南（DOCX / PDF / PPTX）
- 完整 2D 工程模板（ZIP，Unity Hub 直接打开）
- 从零开发手册（DOCX / PDF）

## 环境

- Unity 2022.3 及以上，含 Unity 6
- 2D 项目

## 快速开始

1. 解压 `Unity2D_Game_Dev_Kit.zip`。
2. 已有工程：只导入 `01_Starter_Kit/Unity2D_Starter.unitypackage`，不要替换原有 `Assets`。
3. 没有工程：解压 `02_Full_Project/Unity2D_Full_Project.zip`，用 Unity Hub 打开 `UnityUniversalTemplate` 文件夹。
4. 先打开演示场景按 Play，确认能开始、得分、失败、胜利、重开，再替换素材。

## 说明

模板与文档用于学习、练习和快速原型开发。请遵守所在课程或考试的提交规则。
